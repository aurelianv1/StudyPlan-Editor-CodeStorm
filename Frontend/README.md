# StudyPlan Editor — frontend

Next.js app for the StudyPlan Editor. See the [project README](../README.md)
for setup, configuration and architecture.

```bash
npm install
npm run dev        # http://localhost:3000
npm test           # unit tests
npm run lint
npm run typecheck
npm run build
```

The backend URL is read from `NEXT_PUBLIC_API_URL` (see `.env.example`).
